Request API Full — construir con IA sin delegar el criterio

Proyecto Full Primer incremento del proyecto transversal de la materia

Aquí sí se usa IA, y desde el principio. Lo que no se delega es la decisión: el alcance, el contrato y la organización los defines tú antes de escribir el primer prompt.

«Full» significa
  • Especificación escrita antes de generar
  • Contrato HTTP explícito y documentado
  • Organización en responsabilidades reconocibles
  • Implementación que ejecuta y responde
  • Evidencia de cada caso comprobado
  • Revisión de la IA y comparación con Lite
«Full» no significa
  • Un sistema terminado
  • Todas las operaciones posibles
  • Arquitectura completa por capas
  • Persistencia real de los datos
  • Todo lo que la IA sepa proponer

Es el primer incremento, no un ejercicio suelto

Este proyecto continúa en las clases siguientes. Se comienza aquí, en clase, y se termina como entrega semanal antes del inicio de la clase 3.
