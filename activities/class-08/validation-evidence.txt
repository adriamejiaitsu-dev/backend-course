Nota de portabilidad (Windows)

El script `npm test` del starter usa comillas simples: `node --test
'test/*.test.js'`. En Windows cmd.exe NO elimina las comillas simples y el
patrón llega literal a Node, que encuentra 0 archivos. Por eso la corrida de
arriba usa comillas dobles. En Linux/macOS (donde corre el validador, con
`shell: '/bin/bash'`) las comillas simples funcionan tal cual y el script
original no necesita cambios.

Este NO es un defecto del código del taller: es del shell de Windows.
